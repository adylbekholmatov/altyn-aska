# Алтын-Аска · Приглашение

Сайт-приглашение на торжественную церемонию закладки первого камня
Торгово-транспортно-логистического комплекса «Кызыл-Кия» — **25 сентября 2026**.

- Открытие через бумажный конверт с восковой печатью-логотипом
- Три языка: **русский, кыргызский, английский** (переключатель в шапке и на конверте)
- 3D-галерея архитектурных визуализаций: карусель, наклон за курсором, полноэкранный просмотр
- Обратный отсчёт, «Добавить в календарь» (.ics), карта, «Поделиться»

## Запуск

Сборка не нужна — это статический сайт. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8010
```

Подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel).

## Где что менять

| Что | Где |
|---|---|
| Дата и время начала | `js/main.js` → `EVENT` |
| Русские тексты | `index.html` (элементы с `data-i18n`) |
| Кыргызские и английские тексты | `js/i18n.js` |
| Изображения галереи | `assets/render/` и список `RENDERS` в `js/main.js` |
| Цвета и шрифты | `css/style.css` → `:root` |

Ссылка на нужный язык: `index.html?lang=ru`, `?lang=ky`, `?lang=en`.
