# Алтын-Аска · Чакыруу

«Кызыл-Кыя» соода-транспорттук-логистикалык комплексинин биринчи ташын коюунун
салтанаттуу аземине чакыруу сайты — **2026-жылдын 25-сентябры**.

- Мөөр басылган кагаз конверт аркылуу ачылат
- Сайт кыргыз тилинде
- Архитектуралык визуализациялардын 3D-галереясы
- Фондогу музыка (баскыч менен күйгүзүлөт)
- Тескери эсеп, календарга кошуу (.ics), карта, «Бөлүшүү»

## Ишке киргизүү

Курама керек эмес — бул статикалык сайт. `index.html` файлын браузерде ачыңыз же жергиликтүү серверди иштетиңиз:

```bash
python -m http.server 8010
```

Каалаган статикалык хостинг ылайыктуу (GitHub Pages, Netlify, Vercel).

## Эмнени кайдан өзгөртүү керек

| Эмне | Кайда |
|---|---|
| Башталыш күнү жана убактысы | `js/main.js` → `EVENT` |
| Сайттагы тексттер | `index.html` |
| Скрипттеги тексттер (галерея, календарь, билдирүүлөр) | `js/main.js` → `TEXT` |
| Фондогу музыка (YouTube видеонун ID) | `js/main.js` → `YT_ID` |
| Галереянын сүрөттөрү | `assets/render/` жана `js/main.js` → `RENDERS` |
| Түстөр жана шрифттер | `css/style.css` → `:root` |
